# Arcaea Best50 视频生成器

Windows 桌面应用。导入 Arcaea Best50 成绩，校对结果和录像素材后生成视频。

## 当前功能

- 导入一张 Yurisaki 版式的 Best50 图片（1920 × 1750），或导入成绩 JSON。
- 识别分数、定数、单曲 PTT、通关类型和判定数；通过曲绘匹配曲目，识别不确定时提示校对。
- 导入后逐首获取谱面录像，复用完整录像缓存；缺少来源时可粘贴 B站／YouTube 视频链接或选择本地 MP4。
- 在「识别信息」页预览录像，用同一条双端点滑条或分:秒输入设置单曲开始、结束时间，点击「应用片段」后生成视频使用该区间。未设置时取前 10 秒；修改区间只重渲该曲片段，不重新下载录像。
- 在桌面界面中修改成绩、检查工具状态并生成视频；素材未就绪时会提示对应曲目。
- 提供命令行渲染入口，用于处理已有的项目数据。

片段时间支持 `1:23`、`1:23.5` 等格式。开始晚于结束、时长为 0、超出录像时长时会分别提示。设置保存在当前项目中，重新导入成绩后需重新选择。

导入成绩后进入「填写感想」，录像在后台继续获取。感想可填写名称和多段文字，每段平分时长，并单独添加多张装饰图、拖动和缩放。背景使用 `templates/thought-bg.png`。BGM 可选 OP1–7、自定义音频或静音；选音乐时用双端滑条或分:秒输入截取，视频时长跟随音乐区间，静音时单独设置时长。点击「保存片段」写入本次作品；可继续新建多段感想，并在列表中切换、修改或删除，每段独立预览。保存后显示状态，未保存修改会在切换或新建片段时提示。退出应用或重新导入后清空。当前本地 OP1–7 已放置；放置方式见 [音频说明](templates/audio/README.md)。WAV 不入源码仓库，发布期计划作为可选资源包下载。05 页目前可查看已保存片段，插入位置和转场尚未实现；自制样式放在后续版本。

## 从源码构建

需要 Windows、Go、Node.js、Wails v2、Python 3.12，以及 ffmpeg 和 ffprobe；自动获取录像还需 yt-dlp。Python 只用于构建 OCR 组件，运行应用时不需要单独安装。

本仓库不包含可直接运行的 `data/` 数据包。开发时可从 [资源仓库](https://github.com/IzayoiSakuye/arcaea-b50-resources)生成数据，并将其 `data/` 复制到应用的 `data/`。也可以启动应用，在设置页点击「更新资源」安装已发布的资源包；下载完成后重启应用生效。资源安装在当前用户缓存目录，不写入源码目录。然后构建应用：

```powershell
wails build
node scripts/build-ocr.ts
```

资源清单默认从 Cloudflare R2 获取，失败后依次尝试 GitHub Release API 和 Release 附件；ZIP 优先从清单所在目录获取，GitHub 地址仍可通过公开代理下载。所有来源都必须通过清单中的 SHA-256 校验。可用 `ARCAEA_RESOURCE_MIRRORS` 指定优先尝试的、分号分隔的 `latest.json` 地址。

OCR 构建步骤会生成 `build/bin/ocr/`；使用图片导入功能时，该目录须与 `build/bin/rhythm-game-bvideo.exe` 放在一起。更多构建说明见 [build/README.md](build/README.md)。

已有本地录像和项目数据时，也可运行命令行入口：

```powershell
go run ./cmd/pipeline
```
