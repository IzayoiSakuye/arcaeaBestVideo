# Arcaea Best50 视频生成器

Windows 桌面应用。导入 Arcaea Best50 成绩，校对结果和录像素材后生成视频。

## 当前功能

- 导入一张 Yurisaki 版式的 Best50 图片（1920 × 1750），或导入成绩 JSON。
- 识别分数、定数、单曲 PTT、通关类型和判定数；通过曲绘匹配曲目，识别不确定时提示校对。
- 导入后逐首获取谱面录像，复用完整录像缓存；缺少来源时可粘贴 B站／YouTube 视频链接或选择本地 MP4。
- 在「识别信息」页预览录像，用同一条双端点滑条或分:秒输入设置单曲开始、结束时间，点击「应用片段」后生成视频使用该区间。未设置时取前 10 秒；修改区间只重渲该曲片段，不重新下载录像。
- 可手动新增歌曲，或在「识别信息」页修改成绩、定数、单曲 PTT、评级和录像来源；素材未就绪时会提示对应曲目。
- 可编辑多段感想，并在「编排顺序」页拖动歌曲与感想片段；每首歌曲、每段感想最多出现一次。
- 在「设置」页配置工具路径、检查并更新曲库和 OP 音频、清理缓存。发现资源更新时，导入页会弹出更新提示。
- 按编排顺序生成整片；视频片段首尾及片段交界处的音频使用淡入淡出。
- 提供命令行渲染入口，用于处理已有的项目数据。

片段时间支持 `1:23`、`1:23.5` 等格式。开始晚于结束、时长为 0、超出录像时长时会分别提示。设置保存在当前项目中，重新导入成绩后需重新选择。

导入成绩后可填写多段感想：每段可包含多段文字和装饰图，支持独立预览。BGM 可选 OP1–7、自定义音频或静音；OP 按所选范围循环播放，感想时长可单独设置。感想只保存在本次作品中，退出应用或重新导入后清空。OP 音频不入源码仓库，与曲库资源一起通过应用的「更新资源」获取；缺少 OP 时仍可使用静音或自定义音频。自制样式留待后续版本。

## 安装与使用

从 Release 下载 Windows 安装器。安装后在「设置」页配置自行下载的 FFmpeg、FFprobe 和 yt-dlp；Edge 用于文字渲染。导入 Best50 图片或 JSON，校对成绩并补齐录像来源，填写感想、编排顺序，最后选择输出位置生成视频。YouTube 来源还需要本机 Node.js。曲库和 OP 音频可在应用内一起更新；曲库更新后按提示重启应用。

## 从源码构建

需要 Windows、Go、Node.js、Wails v2、Python 3.12，以及 FFmpeg 和 FFprobe；自动获取录像还需 yt-dlp。Python 只用于构建 OCR 组件，运行应用时不需要单独安装。

本仓库不包含可直接运行的 `data/` 数据包。开发时可从 [资源仓库](https://github.com/IzayoiSakuye/arcaea-b50-resources)生成数据，并将其 `data/` 复制到应用的 `data/`；也可启动应用，在设置页点击「更新资源」。下载的资源安装在当前用户缓存目录，曲库更新后重启应用生效。构建主程序和 OCR 组件：

```powershell
wails build
node scripts/build-ocr.ts
```

资源清单默认从 Cloudflare R2 获取，失败后依次尝试 GitHub Release API 和 Release 附件；ZIP 优先从清单所在目录获取，GitHub 地址仍可通过公开代理下载。所有来源都必须通过清单中的 SHA-256 校验。可用 `ARCAEA_RESOURCE_MIRRORS` 指定优先尝试的、分号分隔的 `latest.json` 地址。

OCR 构建步骤会生成 `build/bin/ocr/`；使用图片导入功能时，该目录须与 `build/bin/rhythm-game-bvideo.exe` 放在一起。制作安装包前须准备本地 `data/`，然后运行 `wails build -nsis`。更多说明见 [build/README.md](build/README.md)。

已有本地录像和项目数据时，也可运行命令行入口：

```powershell
go run ./cmd/pipeline
```
